What these numbers mean

rAF FPS and intervals describe callback cadence, not actual presented frames. Intervals over 25 ms use a 60 Hz reference; they are not a dropped-frame count. Work times measure JavaScript plus explicitly forced synchronous layout or canvas command submission, not GPU execution or total paint latency.

Operation opportunity times extend from operation start through two requestAnimationFrame callbacks: a next-render-opportunity proxy, not guaranteed presentation latency. Keep this window visible, unobscured, and unchanged in size. Browser versions, device pixel ratio, rendering architecture, display refresh rate, power and thermal state can all affect results. Results appear below the measurement stage so controls never cover the workload.
